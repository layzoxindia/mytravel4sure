# Public Launch Checklist

- [ ] Replace local/dev admin password with a unique production secret.
- [ ] Configure persistent database (Supabase for Vercel, or persistent SQLite disk for the bundled Node server).
- [ ] Confirm the WhatsApp number is the business number intended for public enquiries.
- [ ] Confirm every published package price and mark it `confirmed` only when the business has approved it.
- [ ] Confirm final business legal identity/contact disclosures and update Privacy/Terms/Cancellation text accordingly.
- [ ] Connect a real payment provider only after merchant/KYC setup; do not simulate successful payment.
- [ ] Add verified social profile URLs only when they exist.
- [ ] Replace low-resolution reference-derived travel images with licensed high-resolution originals before heavy paid marketing.
- [ ] Add the final public domain to canonical URLs and sitemap locations.
- [ ] Test mobile Safari/Chrome, desktop Chrome/Edge/Firefox and a slow network profile.
- [ ] Back up lead data and define retention/deletion procedures.
